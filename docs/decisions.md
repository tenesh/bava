# Decisions

Dated rows, newest last. A row belongs here when it closes a question that
could reasonably have gone another way.

| Date | Decision | Why |
|---|---|---|
| 2026-09-16 | `nodeMap` is keyed by SVG element id, valued by source span | One structure serves both directions. Click-on-node is a direct lookup; diagnostic-to-shape is a reverse scan, cheap at the sizes this canvas supports. Two maps would be faster one way and a synchronisation risk both ways. |
| 2026-09-16 | ~~Positions cross the boundary as byte offsets plus 1-indexed lines~~ **superseded same day** | Kept as a record: the reasoning was right about converting once in Go, and wrong about the unit. See the UTF-16 row below. |
| 2026-09-16 | `OmitVersion` is set on every render | Measured: D2 emits `data-d2-version="v0.8.1-HEAD"` while running v0.9.0. A golden must not record a version string that is false. |
| 2026-09-16 | `NoXMLTag` is set on every render | The canvas injects the SVG into a div it owns; an XML declaration is invalid in that position. |
| 2026-09-16 | Golden SVGs are compared byte-for-byte with no normalisation | Measured stable across three processes and three in-process calls, with and without a salt: ids derive from content, and TALA's seeds are fixed. A scrubbing step would only hide real regressions. |
| 2026-09-16 | An unknown layout engine is an error, never a fallback to TALA | dagre and elk are alternatives, not fallbacks. A typo that silently changed layout engine would not be noticed for a long time. |
| 2026-09-16 | No `internal/compile/` package | `d2lib.Compile` fuses parse, compile and layout, so the package would be an empty shell wrapping one call. ~~The glob stays registered in `.ai/rules/index.md`, unused, until there is something real for it.~~ **Amended:** the glob has since been removed from `.ai/rules/index.md`. |
| 2026-09-16 | Milestone 1 ships no D2 language mode | Highlighting is a tokeniser plus tests, and it competes with getting debounce, staleness and goldens right. Scheduled as Milestone 10 after the re-plan, before Milestone 12 puts AI-generated D2 into those editors. |
| 2026-09-16 | Positions cross the boundary as UTF-16 code units, via `CompileOptions.UTF16Pos` | Supersedes the row above it. D2 reports UTF-8 bytes; JavaScript indexes UTF-16. Measured: in `café: Café\nweb: Web`, `web` is at byte 13 and UTF-16 index 11, so every marker and jump landed two characters out on any non-ASCII source. An all-ASCII test suite never sees it. |
| 2026-09-16 | The canvas may inject render output with `innerHTML` at D2 v0.9.0 | Probed the actual vectors: `\|html\|` blocks render as syntax-highlighted `<tspan>` text, markdown labels reject HTML elements outright ("native Markdown SVG does not support HTML element `<span>`"), and no `foreignObject`, live handler attribute or `javascript:` URL appears in output. **Re-probe on any D2 bump**: this is a property of v0.9.0, not a guarantee. |
| 2026-09-16 | `@wailsio/runtime` is pinned exactly, matching the Go tag | It floated on `latest` and had resolved to `beta.21` against a Go side pinned to `beta.20`. `.ai/rules/wails.md` forbids floating a version whose betas are near-nightly. |
| 2026-09-16 | Bava is licensed Apache-2.0 | Keeps the MIT dependency stack usable and Mac App Store distribution possible, which GPL-3.0 would foreclose permanently. Adds what MIT lacks and this project needs: an explicit patent grant, and a trademark clause so a fork cannot ship under the name. `NOTICE` carries third-party attribution and feeds the About screen. |
| 2026-09-16 | ~~D2 is dropped entirely;~~ the canvas is free-placement. **D2 part superseded 2026-09-17:** D2 renders once for Diagram from Code and is converted into shapes (row below); `internal/render`, the goldens and `nodeMap` remain | The product is a Figma/Excalidraw-style canvas where the user places and draws anything, not a layout-engine language where an engine computes positions. `top`/`left` pinning was bending D2 into a shape it was not built for. Consequence: `internal/render`, the goldens, `nodeMap` and the diagnostics mapping are retired, and Go stops owning layout and rendering. |
| 2026-09-16 | Konva (MIT) is the canvas foundation | Scene graph, hit-testing and transform handles without writing transform maths. Framework-agnostic, so it sits in Svelte without a second runtime. Rejected: tldraw (licence is not standard open source), embedding Excalidraw (MIT but React), elkjs (EPL-2.0/GPL where dagre is MIT). SVG export must be written by hand, which Fabric would have provided; accepted, since the file format is ours anyway. |
| 2026-09-16 | ~~A `diagram` element stores its D2 source inline~~ **superseded 2026-09-17:** there is no `diagram` element; diagrams become shapes and the D2 source is discarded (row below) | A canvas can hold several diagrams; referencing would scatter a sidecar `.d2` per diagram per canvas, and the binding model assumes the diagram is an object in the same file. Inline keeps a file self-contained. The source is stored as readable D2, not escaped into unrecognisability. |
| 2026-09-16 | ~~Bindings store a node id, never coordinates~~ **superseded 2026-09-19:** a binding stores the attached element's id ("An attached arrow aims at the centre"); the detached rule stands | D2 absolute ids come from source text and survive re-layout; coordinates do not. A binding whose node disappears freezes at its last position and is marked detached, never silently deleted, because the user drew it. |
| 2026-09-16 | Canvas text is measured in the frontend, and the measurement is stored in the file | Measurement had to leave Go once the frontend owned scene layout. The reason the old rule existed did not go away (WebKitGTK and WebView2 disagree on glyph advances), so the mitigation is bundled fonts plus persisted dimensions, which makes a scene reopen identically elsewhere. D2 diagram text is still measured in Go. |
| 2026-09-16 | Geist and Geist Mono, bundled as variable woff2 | SIL OFL 1.1. Variable `woff2` (~70KB per family) rather than 58 static TTFs. Geist for chrome, Geist Mono for code (amended 2026-10-11: and labels and data, `look.md` 7); one token change makes the app monospace throughout if wanted. Replaces the scaffold's bundled-but-unreferenced Inter. |
| 2026-09-16 | One chat thread per file, not per object | The pane serves the document and every diagram on the canvas as a single conversation. A diagram attaches to a *message* as a context reference rather than spawning its own thread, which keeps the per-file JSONL transcript decision intact. |
| 2026-09-16 | A remote icon URL is never fetched | Measured: D2 emits `href="https://…"` straight into its SVG for `icon:` with a remote URL, so the webview would fetch it: opening a file someone sent you would phone a CDN and leak that you opened it. Icons are resolved locally and inlined; a file arriving with a remote URL gets a diagnostic and an explicit one-time fetch offer. |
| 2026-09-17 | Radius, motion and z scales are ours, not the design's | The token sheet specifies none. Radii pinned to the values the mockups actually use (4px dominant, 3px chips, 6px cards). Motion is conservative desktop timing and honours `prefers-reduced-motion`, which the design's own "reduce motion" setting implies. Z-layers exist because Ark ships no z-index and portalled content painted below app chrome in the spike. |
| 2026-09-17 | Two colour tokens added beyond the design sheet | `text-prose` (document body copy, 27 uses in the mockups as `color:` on prose, softer than `text-primary`) and `focus-halo` (described in the sheet's focus recipe but never named). Both evidenced by usage, not invented. |
| 2026-09-17 | No hover or pressed tokens, and no `warning` | Checked the mockups: no such states appear. Adding them now would be inventing a palette nobody asked for. They arrive with the first component that needs one, which is what `design-system.md` already prescribes. |
| 2026-09-17 | Shape colours are scene data, not tokens | The swatches in the design's colour picker are content the user chooses per element. Tokenising them would conflate chrome with the user's own work. |
| 2026-09-17 | All 18 D2 theme slots are mapped, not just the plausible ones | D2 has two colour families that are not interchangeable: neutrals carry text and canvas, the B and A families carry shapes. Measured by rendering with a distinct colour per slot. An unmapped slot keeps its default pale blue and surfaces on whichever shape type uses it (found by rasterising a dark golden and seeing a near-white cylinder, not by a passing test). |
| 2026-09-17 | `Render` rejects a partly-filled theme | A struct with three of seven fields set would render the rest from D2's defaults and look subtly wrong rather than fail, which is the harder bug to find. |
| 2026-09-17 | The no-literals rule is a test, not a grep | `src/styles/no-literals.test.ts` fails the suite on any hex, rgb/hsl or px outside `tokens/`, including in comments. The roadmap's exit criterion was a shell one-liner; a rule enforced only by a command nobody runs decays. |
| 2026-09-17 | The window is 1280×800 | Four regions (files, document, canvas, AI) have to fit side by side, and the design's artboard is 1280 wide for that reason. The scaffold's 1000×618 leaves each region unusable. Pinned by a test so a later change is deliberate. |
| 2026-09-17 | The native window background is no longer set | The scaffold pinned a near-black, which fights `color-scheme: light dark` and flashes dark behind a light page on launch. The webview paints from the token layer instead. |
| 2026-09-17 | Settings is a dialog, not a route | It also exercises the portal path this milestone had to prove, and there is no navigation model to hang a route on. |
| 2026-09-17 | Translations are a typed key map, not a library | One locale, no plural or date formatting yet, so a library would be weight without a use. The rule it enforces (no user-facing string written inline) is the part that matters, and an unknown key fails to compile rather than rendering itself. |
| 2026-09-17 | Document and canvas regions are hidden with CSS, never unmounted | CodeMirror and the canvas own their own DOM and are mounted once. Letting a view switch unmount them would destroy the editor and take its undo history and cursor with it (caught by the App mount test). |
| 2026-09-17 | Class names on Ark's own elements are prefixed | Ark renders those elements itself, so Svelte's scoping cannot reach them and the rules must be `:global()`. A generic `.content` or `.title` leaks across the whole app. |
| 2026-09-17 | ~~Milestone 1's keyboard debt moves to Milestone 4~~ **closed:** there is no click-on-node since diagrams became shapes | Click-on-node jump-to-source still has no keyboard equivalent. Paying it in Milestone 3 meant building selection over the interim canvas that Milestone 4 replaces, so it belongs with the real selection model rather than being built twice. |
| 2026-09-17 | Undo is patch-based, via `immer` | A snapshot per step grows with scene size; hand-rolled inverse operations are where undo bugs live. Immer produces both directions from the same mutation. A mutation that changes nothing records no step, so undo never appears to do nothing. |
| 2026-09-17 | Canvas tests use `vitest-canvas-mock`, not the native `canvas` package | Konva needs a 2D context that jsdom lacks. The native module would have to build on three CI platforms; these tests assert scene patching, not pixels. |
| 2026-09-17 | ~~No spatial index yet~~ **superseded 2026-09-27** by "No spatial index", which measured it | Konva's own hit-testing is sufficient at the sizes this milestone builds. `rbush` answers a measured problem, and Milestone 7 revisits it when bindings need hit-testing into diagrams. |
| 2026-09-17 | Grouping does not move its children | A group is a labelled element that knows its children and covers them; children keep their own coordinates. Ungrouping is then removal of the wrapper rather than an inverse transform, which is the version that cannot drift. |
| 2026-09-17 | ~~The D2 preview is absent between Milestones 4 and 6~~ **closed:** the preview lives in the Diagram from Code dialog | The canvas pane is a drawing surface now; a rendered diagram becomes an element on it in Milestone 6. The pipeline still runs and is still tested (diagnostics still reach the editor), but nothing paints the SVG. Accepted rather than building a diagram element twice. |
| 2026-09-17 | A Bava file is Markdown with a trailing `bava-canvas` block | Options two and three (two file types, or a sidecar) both lose the canvas silently on a rename, a partial copy, or `git add` of one file. For an app whose premise is that these are the user's files, that is not an edge case. A fenced block cannot be separated from its document, and every Markdown tool preserves a fence it does not recognise. Cost accepted: a JSON block at the end of a human document. |
| 2026-09-17 | Markdown is scanned, never parsed | We need fenced blocks with their info strings and every other byte untouched. A real Markdown parser round-trips prose approximately (normalising whitespace, rewriting emphasis, reordering reference links), and approximate is a synonym for corrupting a file someone else wrote. |
| 2026-09-17 | Saves are atomic | Write to a temporary file in the same directory, fsync, then rename. A crash mid-save leaves the old file or the new one, never a truncated one. Same directory because a cross-filesystem rename is not atomic. |
| 2026-09-17 | Saving into a directory that does not exist is an error | Silently creating directories turns a typo in a path into a mess of empty folders. The user asked to save one file. Bava's own config directory is the exception: that file is ours. |
| 2026-09-17 | Conflict detection is size plus modification time, not a hash | Enough to prompt, and cheap enough to check on every focus change. A hash would mean re-reading every open file each time. |
| 2026-09-17 | Preferences live in the platform config directory | They are Bava's state, not work product. A settings file that cannot be read or makes no sense falls back to defaults rather than stopping the app, including per-value, so a negative debounce or an unknown engine is replaced rather than propagated. |
| 2026-09-17 | Recent files stay in `localStorage` | A convenience, not work product. Milestone 16 can promote them if the settings UI wants them. |
| 2026-09-17 | A drag is one undo step | However many pointer events a drag produces, it records one history step. A user who drags a shape across the canvas expects one undo to put it back, not fifty. |
| 2026-09-17 | Movement under three pixels is a click | Below the threshold, a shape tool or the pen creates nothing. Otherwise a click leaves a zero-size element that cannot be selected or explained. |
| 2026-09-17 | Canvas repaints from a published snapshot, not a counter | The scene is deliberately not reactive, so the render effect needs something to subscribe to. Publishing the current snapshot makes that dependency the actual data rather than a bare expression read for its side effect. |
| 2026-09-17 | Saving and opening policy lives in `files/actions.svelte.ts`, not markup | It is exactly the logic that was broken (see the Milestone 5.5 completion record), so it is tested directly: untitled saves, the unsaved-changes prompt, and the conflict prompt. |
| 2026-09-17 | ~~"Open" opens a file and lists its folder~~ **superseded 2026-09-27** by "⌘O opens a Space; ⇧⌘O opens a file" | There is no separate folder picker yet. Opening a file is the common case, and showing its siblings covers most of what a folder picker would. |
| 2026-09-17 | The native menu is data | `internal/app/menu/spec.json` declares the whole tree (submenus, radio groups, platforms), so adding an item is a data change checked by tests: unique ids, unique accelerators including those native roles bind, every id handled in the frontend, every accelerator documented. Grouped for growth now, because Import, Export, Find and Insert are already on the roadmap. |
| 2026-09-17 | No accelerator without a modifier | Tool keys (`V`, `R`, …) are shown in the menu as hints, never bound. A native accelerator on a bare key fires before the webview sees it and would steal the letter from every text field. |
| 2026-09-17 | `⌘B`, `⌘I`, `⌘U`, `⌘K`, `⇧⌘X` are reserved | Prose formatting in Milestone 8 needs them, and a menu item that takes one first is a rename nobody wants later. Enforced by a test. |
| 2026-09-17 | Menu-bound shortcuts leave the JS keymap | A shortcut handled in both places acts twice per keypress: two undos, two pastes. The canvas keymap now handles nothing with Cmd or Ctrl; a test reads the spec's accelerators to hold it there. |
| 2026-09-17 | Edit commands route by focus | Undo, Redo, Cut, Copy, Paste, Select All and Delete arrive from the menu rather than as keys, so the focused element decides: the source editor, the browser for a text field, or the canvas, and nothing while a dialog has focus or the canvas is hidden, so Select All then Delete cannot empty a canvas nobody can see. Delete is a custom item with no accelerator, because the native Delete role binds bare Backspace. |
| 2026-09-17 | Cut, Copy and Paste are commands, not native roles | On Windows the roles run `navigator.clipboard` scripts in the page, and on Linux `execCommand('paste')`, which WebKitGTK blocks; neither reaches the canvas. Text goes through the Wails clipboard API, which behaves the same on all three and asks no permission. Cost: macOS loses the native text services those roles bring. |
| 2026-09-17 | Punctuation shortcuts are handled by the page | Wails on Windows matches accelerators by virtual-key name and never fires `CmdOrCtrl+=`. Such items carry a `shortcut` the menu displays and the page matches by physical key (`event.code`), so `⇧⌘]` works although Shift turns the key into `}`. |
| 2026-09-17 | Menu labels are English in the spec, for now | The i18n rule says no inline user-facing strings; the menu spec is the exception, because Go builds the menu before any frontend exists and there is one locale. When a second locale arrives, labels become message keys resolved on both sides. Role labels are not in the spec at all: Wails derives them from the application name, which is `Bava` for that reason. |
| 2026-09-17 | Loading a document resets history | Opening a file or starting a new one is not an edit. Recording it as one let undo after File ▸ New bring the previous file's shapes back. |
| 2026-09-17 | A save marks the document clean only if nothing changed while it wrote | Autosave writes while the user works. An edit made during the write is not on disk; clearing `dirty` anyway would skip the unsaved prompt and lose it. The document counts edits and compares. |
| 2026-09-17 | Autosave is off by default | Writing to someone's files unasked is their choice. Modes follow VS Code's `files.autoSave`: `off`, `afterDelay` (1000ms default, clamped to 200–60000), `onFocusChange`. An unknown mode reads as off, never a guess at a different kind of autosave. |
| 2026-09-17 | Autosave never writes an untitled document | That would need a save dialog nobody asked for, or a path made up for them. |
| 2026-09-17 | A conflict pauses autosave without prompting | A dialog appearing mid-sentence because a background save found a conflict is worse than no autosave. The status bar says so; the next save by hand raises the normal conflict prompt and resumes autosave. |
| 2026-09-17 | Open and Save left the title bar | They live in the File menu, where a desktop user looks for them. The title bar keeps the filename, the view switcher, and the AI and Settings toggles. |
| 2026-09-17 | The brand mark is paper on ink, always | The v2 brand handover's rule replaces the roadmap's earlier "ink on light, paper on dark". On a light ground the mark carries its own ink tile; it never inverts. Held in two tokens, `--color-mark` and `--color-mark-tile`, so no component decides it. |
| 2026-09-17 | App icons are designer exports, not generated in-repo | Each platform wants a different master and the construction is a design decision (sheet 06). Generating them would add an SVG rasteriser dependency to reproduce what a designer already drew. Cost accepted: a change to the mark needs a new export. |
| 2026-09-17 | The mark ships without its C2PA manifest | The export embedded ~7KB of provenance metadata. The app ships the drawing; a test pins the path data by SHA-256 so stripping cannot alter it. The repo holds the only copy the product depends on; design folders outside it are temporary. |
| 2026-09-17 | No Assets.car until Xcode is available | macOS 26 prefers the compiled asset catalogue over `icons.icns`, and the template's held the Wails logo. It cannot be rebuilt without `actool`, so it and `CFBundleIconName` are removed. The Liquid Glass icon is deferred. |
| 2026-09-17 | About shows no version yet | There is no version stamping until Milestone 16. A placeholder number would be a false claim in the one place people look for the truth. |
| 2026-09-17 | DMG installer art waits for release | The DMG's file icon and background are still the Wails template. Nothing ships a DMG before Milestone 16, so replacing or dropping them belongs with packaging there rather than commissioning art now. The volume icon already uses Bava's `icons.icns`. |
| 2026-09-17 | The empty-state mark fades only in the dark theme | The brand sheet fades the mark to 32% but shows only a dark ground, where the mark is bare. On light the mark carries an ink tile, and fading it makes a mid-grey ground the misuse sheet forbids. The fade is a per-theme token: 0.32 in dark, 1 in light. |
| 2026-09-17 | Chat rendering: `markstream-svelte` is the candidate, subject to a spike | One library for streamed markdown and code blocks beats wiring two. Its Svelte port is beta and its network and theming behaviour are unverified, so Milestone 11 opens with a spike gating adoption on zero network requests, theming to tokens, bundle size without Mermaid, and smooth streaming. Fallback: `@humanspeak/svelte-markdown` with Shiki. Tailwind-based kits (Svelte AI Elements, shadcn-svelte) are ruled out. Provider calls stay in Go whichever renders. |
| 2026-09-17 | Menu hints appear in labels on Windows only | Seen at a running window: macOS and GTK do not right-align text after a tab, so hints landed mid-row. On macOS `⌘,` `⌘=` `⌘-` `⌘/` become native accelerators, which AppKit aligns; everything else is listed in Help ▸ Keyboard Shortcuts rather than drawn out of line. |
| 2026-09-17 | Errors and logs stay on the user's machine | Release builds of Wails discard every log line, and a panic outside a bound method exits silently. Bava keeps per-session logs locally (10 sessions, 50 MB), shows plain-language dialogs with Copy Details and Open Logs Folder, and never uploads anything: a report leaves the machine only when the user sends it. Logs never contain document content, prompts or credentials, held by a test. Spec: `.claude/work/specs/errors-and-logs.md`. |
| 2026-09-17 | Report Issue is hidden until release | The destination must be a public tracker, which is confirmed in Milestone 16. The item and its template are built in 5.8 behind one constant. |
| 2026-09-17 | The first unexpected error opens a dialog; later ones only note the status bar | A failure repeating in a loop must not stack modals. Everything is logged regardless. Startup notices (the last session ended unexpectedly, the window was reloaded) each open once. |
| 2026-09-17 | A crashed panel is contained, and reloading it loses its undo | `<svelte:boundary>` keeps a render error inside one region. Reloading the document or canvas panel remounts its editor, so the fallback says plainly that its undo history goes. |
| 2026-09-17 | Logs never hold file paths or names | Found writing the privacy test: a file name can be content. Logs carry sizes, counts, durations and outcomes; the path stays in the UI where the user sees it. |
| 2026-09-17 | Wails gets a warn-only logger with no attribute values | Found in review: Wails logs every bound call's arguments and result at debug level, which is document content. Sharing the session logger would have written documents into the log whenever verbose was on. |
| 2026-09-17 | A panic inside InvokeSync exits | Wails does not defer `wg.Done()` there, so a handler that returns leaves the caller waiting forever: a bound call that never answers, or a quit that never finishes. Exiting leaves the session marker, and the next launch reports it. |
| 2026-09-17 | Frontend errors are logged by kind and frames, never message | JavaScript messages quote input. The dialog's details show only what the log keeps. |
| 2026-09-17 | One marker per session, keyed by PID | Two windows of Bava at once must not report each other as crashed or prune each other's live logs. |
| 2026-09-17 | Elements carry every key across the frontend bridge | Found planning Milestone 6: saving from the app dropped a stroke's points, a text element's text, a group's children and every unknown key, because `format.Element` kept them in a `json:"-"` field. Element and Scene now encode and decode themselves whole, tested on the read, bridge, write path. |
| 2026-09-17 | Shape colours are eight named swatches plus the theme default | `gray`, `blue`, `green`, `yellow`, `orange`, `red`, `purple`, `pink`, each with fill, border and text values in light and dark. A file stores the name. Arbitrary colours wait for Milestone 15. |
| 2026-09-17 | A shape's label is not separately measured | It wraps inside the shape's box, so a glyph's difference between webviews reflows it within the box and moves nothing else. Free text elements still store their measured size. |
| 2026-09-17 | Resize goes through the pointer handler, not Konva's Transformer | One input path: the Transformer's anchors take Konva events, so a press on one would also start a move in the pointer handler. The stage draws the outline and handles only. |
| 2026-09-17 | Scaled geometry is rounded to three decimals | Resizing by a ratio leaves floating-point dust (220.00000000000003) that would otherwise be written into the user's file. |
| 2026-09-17 | The file writer does not HTML-escape | encoding/json turns "<", ">" and "&" into "\u003c" and friends by default, which rewrote labels like "A -> B" on every save. |
| 2026-09-17 | Placing text is one undo step | The text tool opens the editor at the click and records nothing until text is typed. Recording an empty element first left an invisible, unselectable element behind after undo. |
| 2026-09-17 | Text block size is the widest line and one line height per line | Measured as one line, multi-line text stored a single line's height and Konva drew only the first line. The stage and the measurement share `--text-body` and `--leading-tight`. |
| 2026-09-17 | Canvas keys leave Enter, Space, Tab and arrows to a focused control | Handled at window level, they cancelled button activation everywhere outside fields and dialogs. Tool letters and Delete still reach the canvas. |
| 2026-09-17 | Canvas drawing sizes are tokens; behavioural constants stay named in code | Handle size, label inset, arrowhead, stroke widths and editor minimums are `--size-*` tokens. Resize minimum, zoom step and wheel sensitivity are named constants beside the logic they tune. |
| 2026-09-17 | Bava launches with no file open | Launching into an untitled document with demo D2 source showed content nobody wrote. The window shows the no-file state (title bar, faded mark, Open and New keys, status bar); New or Open leaves it. Regions stay mounted underneath. See `.claude/work/specs/launch.md`. |
| 2026-09-17 | A splash covers startup, with an indeterminate bar | It shows until settings and fonts have loaded, capped at 2 seconds. Nothing reports real progress, so no percentage; no version, because nothing stamps one yet. |
| 2026-09-17 | Settings is reached only from the native menu | The title bar's Settings button duplicated Bava ▸ Settings… (macOS) and File ▸ Settings… (Windows, Linux). |
| 2026-09-17 | The log session closes in `PostShutdown` | On macOS `[NSApp terminate:]` exits the process after Wails' cleanup, so `Run` never returns and closing after it never ran: every quit was reported as a crash. `PostShutdown` is the last cleanup step, after services stop. The call after `Run` is still required: on Windows, closing the last window posts `WM_QUIT` and skips cleanup, so `Run` returns without `PostShutdown`. `Session.Close` is idempotent. On Linux, a non-zero exit after cleanup is logged into the closed session and lost. |
| 2026-09-17 | Diagrams become free shapes; Diagram from Code renders D2 once and converts it | Replaces the live `diagram` element. D2 lays the diagram out once and the result is converted into ordinary canvas shapes and arrows (`frontend/src/canvas/import/convert.ts`), which move, restyle, connect and delete like anything drawn by hand. The D2 source is discarded, so no element refers to a `d2` block and nothing keeps a second copy in sync. Spec: `.claude/work/specs/diagrams-as-shapes.md`. |
| 2026-09-18 | Excalidraw's properties panel is the baseline for canvas controls | Eraser does not document its selection toolbar. Adapted: no sloppiness, hatch fills or font choice (Bava bundles Geist only); theme-aware swatches, not a fixed palette. See `.claude/work/specs/canvas-toolbar.md`. |
| 2026-09-18 | Comments are dropped | Bava is local only with no sharing: a comment has no one to address. |
| 2026-09-18 | An icon rail with an insert panel replaces the labelled rail and shape menu | Common tools on the rail with key letters and tooltips; every other shape in the insert panel (`/`), searchable. |
| 2026-09-18 | A right-click menu and a bottom selection toolbar, grouped, with submenus | One tree (`canvas/context-menu.ts`) serves right-click and More; only working actions are listed. |
| 2026-09-18 | ~~Arrange, align, distribute, flip, duplicate and copy/paste styles are canvas-scoped shortcuts~~ **superseded 2026-09-26** by "Only necessary shortcuts are bound" | The same keys mean something else in the source editor and in text fields; a `scope: "canvas"` entry acts only when the canvas has the keyboard.
