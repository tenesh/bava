# Search across a Space, decisions

Settled with the user before the plan, one question at a time, for
Milestone 15 (`documents.md` decision 58 sends Space-wide search there).

### 1. Milestone 15 is built in four parts, search first (2026-10-11)

15.1 search across a Space; 15.2 export (PDF and the Markdown zip); 15.3
import; 15.4 the canvas work the roadmap parks in Milestone 15. Each is
planned, gated and committed on its own. Search first: the smallest part,
and the one used every day.

### 2. Search looks at names, page text and canvas text (2026-10-11)

Page and folder names; every page's Document; the words on its Canvas
(shape and arrow labels, text elements, code blocks, frame names). A
diagram is found by what is written in it.

### 3. Search opens as a palette over the window (2026-10-11)

A box at the top centre of the window: type, results show as you type,
the arrow keys move and Enter opens. Chosen over a Search section in the
side pane, and over both. Its shortcut is settled below: ⌘K, first
offered, is already Link in a page.

### 4. One row per page, with its best match (2026-10-11)

Chosen from three drawn options (since deleted): each page or folder that
matches once, its name and folder on the row and its best match beneath,
the search word marked; the number of matches at the row's end. Enter opens
the page at its first match. Chosen over every page's matches listed under
it, and over every match on its own row.

### 5. ⇧⌘F (Ctrl+Shift+F) opens search (2026-10-11)

Beside ⌘F, find in this page, as "find in all files" is in most editors.
⌘K stays Link in a page. Also in the menus (File ▸ Search).

### 6. Every word, anywhere on the page (2026-10-11)

Capitals are ignored. A page matches when it holds every word typed, in any
order and place (its name, Document and Canvas counted together); a word
matches the start of longer words too ("launch" finds "launches").

### 7. A canvas match opens on the Canvas, selected and in view (2026-10-11)

The page opens on its Canvas (in Both when the Document is showing), the
element that matched selected and panned into view. *Extended by decision 9:*
it opens with the Canvas's find bar, filled with the matched word.

### 8. A Document match opens with the find bar (2026-10-11)

The page opens scrolled to the match, with the page's find bar (⌘F) open
and filled with the matched word, every place it appears marked and the
snippet's match the current one; Enter steps on, Esc closes the bar. With
several words searched, the bar takes the word the snippet matched, as
find looks for one phrase.

### 9. The Canvas gets a find bar too (2026-10-11)

Asked by the user: "does it do the same for canvas find bar?" There was
none. ⌘F on the Canvas opens the same bar as in a page: every element whose
text matches (a label, a text element, a code block, a frame's name) is
outlined, the current one selected and panned into view; Enter and ⇧Enter
step, Esc closes. Find only, no replace. A canvas search result opens with
it, filled with the matched word. Built in 15.1 with search.

### 10. Before anything is typed, only a hint (2026-10-11)

"Search pages, folders and canvases" until a word is typed; no recent pages.

### 11. Only the Space's pages (2026-10-11)

What the Files tree holds: pages and folders. Not templates (their own
dialog finds them) and not the Trash (trashed pages are not part of the
Space until restored); nothing under `.bava`.

### 12. A page outside a Space offers to become one (2026-10-11)

As embeds and media do: ⇧⌘F on a loose page asks to open its folder as a
Space; yes opens the Space, then the search.

### 13. A folder result shows the folder in Files (2026-10-11)

The palette closes; the side pane opens if hidden; the folder is unfolded,
selected and scrolled into view in the Files tree.
