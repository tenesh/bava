# 8.6: Tags and templates, decisions

Settled with the user before the plans, one question at a time. They fill
holes in decisions 47, 53, 60, 63, 66 and 75 of `08-documents.md`, which
stand.

### 1. Built in two parts, tags first (2026-10-06)

8.6a Tags, then 8.6b Templates, each planned, checked and committed on its
own. Tags first because a template can carry tags.

### 2. A tag is lowercase, with no spaces (2026-10-06)

The user, after first choosing any words: "tags should be in lowercase and
no space." Other characters are allowed. Written in the page's front matter
as a YAML list (`tags: [launch, q4]`), quoted where YAML needs it. Capitals
cannot make two tags of one.

### 3. Typing converts; other tools' tags are read the same way (2026-10-06)

As a tag is typed, capitals become lowercase and a space becomes a dash
(`Road Map` gives `road-map`). A tag another tool wrote with capitals or
spaces (`Launch`, `Road Map`) is shown and matched converted, and the file
is rewritten only when that page's tags are edited.

### 4. Tags sit at the bottom of the page, as Confluence's labels (2026-10-06)

The user: "should be like confluence page, at the bottom of the page." A
row of grey chips after the page's content, before Linked from, with
"+ Add tag" at its end. Decision 66's "under its title" is replaced.

### 5. Tags are a filter in Files, not a section of their own (2026-10-06)

Replaces decision 66's Tags section. A tag button in the Files header opens
the Space's tags with their page counts; the tags chosen show as chips
above the tree until cleared, and the tree shows only the pages that have
**all** of them, with the folders that lead to them opened. A tag's menu
(rename, merge, delete) is reached from that list.

### 6. A tag's menu: Rename, Merge into, Delete (2026-10-06)

The user kept the three of decision 66. Rename refuses a name another tag
has; Merge into picks another tag from a list, and a page with both keeps
one; Delete takes the tag off every page, the pages kept. Each rewrites the
pages that have the tag.

### 7. A Tags dialog manages them, several at once (2026-10-06)

From the mockups the user approved
(https://claude.ai/artifact/NnuULeWaD8MrJDEe7SJY2M, reference, not spec): a
**Tags** dialog, like Media, opened from the tag list's "Manage tags…" and
the Space switcher. It lists every tag with its page count, searchable and
sorted by name or by pages. A tag is renamed in its row (a name another tag
has is refused, pointing to Merge into). Boxes select several; a bar then
offers **Merge into…** (one tag they all become) and **Delete**. Each row's
⋯ has Rename, Merge into and Delete for that tag. Delete and Merge ask
first, naming the tags and how many pages change; the pages always stay.
The tag list in Files keeps its own ⋯ menu per tag.
