# 08.4b: One testing standard

**Goal:** every test follows one written standard, so tests read the same,
share their helpers, clean up after themselves and cannot pass by timing.

**Specs:** `docs/testing.md` ("The standard"), `.ai/rules/testing.md`; the
three audits of 2026-10-03 (Go, frontend unit, screen checks and smoke).

**File format impact:** none. **UI impact:** none; screen check references
are renamed and recropped, each read before kept.

## Constraints
- Tests and their helpers only. A test that finds a defect gets it fixed
  test-first, listed in the As built.
- The app is never launched locally; screen checks run in Docker; smoke on CI.

## Tasks
### Task 1: The standard and the agents
`docs/testing.md` "The standard"; `.ai/rules/testing.md` points to it;
`.claude/agents/auditor.md`, `visual-reviewer.md`. Done.

### Task 2: Go tests
`internal/testutil` (repo paths, file trees, JSON keys, goldens) replacing
the per-package copies; names to the standard; the weak tests strengthened
or deleted; JSON-key tests for every bound result type; no sleeps or
wall-clock bounds; restores through `t.Cleanup`.
- [x] Green: `go vet ./internal/... .`, `go test ./internal/... .`
