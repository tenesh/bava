# 08.6b: Templates

**Goal:** a Space keeps its own page templates, in groups, managed in a
Templates dialog and edited like pages; Add makes a page from one, and a
page can be saved as one.
**Specs:** `.claude/work/specs/08-documents.md` decisions 47, 53, 60 and 63;
`.claude/work/specs/08.6-tags-and-templates.md` decisions 8 to 12
(2026-10-07); `docs/file-format.md` (Spaces, `.bava/`); `docs/ipc.md`.
**File format impact:** a new Space folder, `.bava/templates/`, specified in
`docs/file-format.md` first: each template an ordinary page file, a group a
folder in it. No change to a page's own format.
**UI impact:** added: `TemplatesDialog` (the Templates dialog),
`SaveTemplateDialog` (name and group), `TemplateBar` (above a template
being edited). Reused: `Dialog`, `ContextMenu` (Add's submenu, a
template's menu), `ConfirmDialog` (delete, replace). Strings
in `messages.ts`; tokens added first if any are needed.

## The file form

```
My Space/
  .bava/
    templates/
      Meetings/
        Weekly sync.md
        Retro.md
      Bug report.md        (in no group)
```

- A template is a page file: front matter, prose and canvas block, read
  and written as a page is.
- A group is a folder directly in `templates/`; deeper folders are not read.
  A group with no templates left is removed.
- A template's links and media addresses are written relative to the
  template's own place, as a page's are to its own; a page made from it, or
  a template saved from a page, has them rewritten for where it lands.

## Constraints

- Groups are folders (decision 8). Add's "New page from template ▸" lists
  them by group, ungrouped after (decision 9). A template is copied as it
  is: no fill-ins (decision 10). Edit opens it like a page, under a bar
  naming it with Done; it never shows in the Files tree (decision 11).
  Delete asks, then removes the file for good (decision 12).
- Defaults settled in the plan:
  - **Save as template** (page menu, and a page's right-click in Files)
    opens a small dialog: name (the page's to start with) and group (an
    existing one, none, or a new name). A name taken in that group asks to
    replace it.
  - **A page made from a template** is named in place in the tree, as New
    page is, starting with the template's name; its tags, document and
    canvas are the template's.
  - **The Templates dialog** (File ▸ Templates and the Space switcher)
    lists templates by group, searchable; New template (an empty one,
    opened to edit), and per template: Edit, Rename, Move to group,
    Duplicate, Delete.
  - A loose page offers to become a Space before Save as template, as with
    media.
- Names follow page names' rules (Go's `validName`); a group's name too.
- Go owns the files: listing, writing, renaming, moving, duplicating and
  deleting templates, and writing a page or template from text and scene
  through `internal/format`. No service of ours.

## As built

A Space's templates live in `.bava/templates/`, a group a folder there.
Add (and a folder's right-click) has New page from template ▸, by group:
the page is named in place, starting with the template's name, then made
from the template's text and canvas with its links and images rewritten
for where it lands. Save as template, in the page menu and a page's
right-click, asks a name and a group (picked or typed) and asks before
replacing. File ▸ Templates and the Space switcher open the Templates
dialog: search, New template, and per template Edit, Rename, Duplicate,
Move to group, Delete (asked, for good). Editing opens the template like a
page, under a bar with Done; its crumbs read Templates and its group.

**Checks:** `npm test` 2,759 passed and 1 skipped (214 files); `npm run
browser` 462 passed, twice in a row, exit 0, no unused references; 8 new
pictures (the Templates dialog, Save as template, a template being edited,
Add's submenu) and the switcher's open pictures retaken, read in both

**Deviations**

- **A pre-existing bug fixed:** New page (and New folder, Rename) chosen
  from the Files Add menu or a row's right-click ended its naming at once:
  the menu's close gave focus back to what opened it, which took it from
  the name field. Those actions now start once the menu has closed
  (`onClosed`); an integration test covers New page from Add.
- **Move to group** offers the Space's existing groups and No group; a new
  group is made by saving or making a template into it.
- **The page menu of a template** keeps only Lock and Width: Duplicate,
  Save as template and Move to Trash are a page's, not a template's.
- **New template** reuses the Save as template dialog with its own title,
  saves an empty template, and opens it to edit.
- **Go:** `SaveTemplate` and `CreatePageFrom` are bound methods taking text
  and scene, written through `internal/format`, beside the `Apply`
  operations for renaming, moving, duplicating and deleting; templates have
  their own path check, as the Space's refuses anything hidden.
- **The stand-in keeps templates with its pages** under their own paths, so
  editing one opens and saves as a page does.

- **The end-to-end walk saves a template and reads its file back**, but
  does not make a page from it: that path runs through nested menus and
  naming in place, covered by the integration test with the stand-in.

**Review:** one blocker, fixed: a template written or moved into a group
whose folder was a link (or under a `.bava` or templates folder that was
one) was written through it, out of the Space. Every template operation
now refuses a folder that is not a plain one (`throughLink`), tested for
groups and the templates folder; every operation is tested against paths
outside templates. Also fixed: a page made from a template whose content
cannot be written is removed (`CreatePageWith`); `space.Template`'s JSON
keys pinned; no trailing ellipsis on the new labels, nor on the tag labels
from 8.6a (your rule); the bar's place line from `messages.ts` and the bar
a named region, not a live one; a double-click no longer opens a template
twice.

**Left to a person at a running window:** the menus' submenus on each
platform's webview, editing a template with its canvas, and the end-to-end
`create` walk's Save as template steps on CI.
