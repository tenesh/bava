# 08.2: The Document editor

**Goal:** a page's prose is edited as formatted text, Notion-style, and saved
as tidy Markdown, replacing the scratch D2 pane that has never shown or saved
a page's text.

**Specs:** `.claude/work/specs/08-documents.md` decisions 1, 12, 15 to 18, 38,
43 to 45, 51, 56, 57, 60, 64, and 75 and 76 (settled for this plan);
`docs/file-format.md` ("The shape": prose first, canvas block last);
`.ai/rules/editors.md`; `CLAUDE.md` (ProseMirror, runes, mounting, no
Markdown shown); the Bava Design mockups: the Document board (page header,
⋯ menu, block handle, `+`), the Menus board (`/` menu, formatting bubble,
block and page menus).
**File format impact:** yes, specified first in `docs/file-format.md` (Task 1):
the page's front matter (`bava:` `locked`, `width`), Bava's Markdown style
(decision 51), the invisible marks and inline HTML (decision 76), and blocks
this part cannot edit yet being kept byte for byte.
**UI impact:** the Document pane becomes a ProseMirror editor with a page
header (breadcrumb, ⋯ menu), a `/` menu and `+` button, a formatting bubble,
a block handle and its menu, and a find-and-replace bar. New components are
wrapped per the design system; new tokens for the editor's type scale and
block spacing are added before the components that use them.

## Constraints

- **Markdown is never shown while editing** (decision 1), not even on the
  line being edited. The file stays Markdown (non-negotiable 2).
- **Nothing is lost.** Any block this part cannot edit yet (fenced code and
  `d2` blocks, tables, HTML blocks, callouts, footnotes, equations, anything
  unknown) is kept **byte for byte** as a read-only block in the page and
  written back unchanged. Unknown front matter keys are kept. The canvas
  block is untouched: the editor edits only the prose (`doc.source`), as
  today.
- **Saving tidies the page** (decision 51) in one documented style; a second
  save changes nothing (idempotent).
- **Empty lines close up** on save (decision 17).
- **Nesting:** lists and quotes only; Tab and Shift+Tab (decision 16).
- **The title is the first heading** (decision 56); the tree keeps showing the
  file name.
- **Page width:** the page's own override, else the Space's default (8.1),
  else the app-wide default in Settings (a per-viewer preference in the
  config file, never in a page). Narrow, Wide, Full.
- **Lock** makes the page read-only for anyone who opens the file until
  unlocked; the ⋯ menu shows the state.
- **One page open at a time** (decision 64); leaving with unsaved changes
  asks, unless autosave is on (unchanged from today).
- **Undo:** the editor keeps its own history, routed by focus as the source
  and code editors already are (`shell/edit-target.ts` gains `document`).
  Undo across a CodeMirror node inside ProseMirror (one history, per
  `.ai/rules/editors.md`) arrives with code blocks in 8.3, not here.
- **Mounting:** the editor is a TypeScript class, mounted in `onMount`,
  destroyed in the cleanup; no reactive props flow into it (editors rule).
- **Libraries:** ProseMirror's packages and `prosemirror-markdown` with
  `markdown-it` (all MIT), pinned exactly; `NOTICE` gains their entries.
- **Tests:** every file-format rule has a round-trip test; every editor
  command with logic has a unit test; every new screen and state has a screen
  check walk in both themes; the smoke scenario types into a page, saves and
  reopens.

## As built

- **Page settings:** front matter is read and written in `docs/markdown.ts`
  (`readFront`, `writeFront`), next to the rest of the file format. The width
  order (page, Space, app, else wide) is `pageWidth` in
  `docs/page-settings.ts`, with its own tests; the pane takes the Space's and
  the app's widths as props.
- **The Document side no longer shows the D2 source pane.** `SourcePane` stays
  for the Diagram dialog and code blocks; the status bar's D2 error count went
  with it.
- **Found by the screen checks, fixed with a check that fails without the
  fix:**
  - a paragraph had no gap above it, because the element reset outweighed the
    block rhythm;
  - the to-do box sat above its line and showed no tick;
  - find marked no match;
  - the formatting bubble showed over the title while typing in the find
    field. It now shows only while the page has focus.
- **The smoke driver** places a caret at the end of an editable page it
  clicks, so the scenarios can type into the Document. The scenarios were not
  run on this machine, because the smoke build uses the real settings folder
  and would add a Space to the recents. They are owed a push.
- **Owed at a running window:** the keyboard pass over the `/` menu, bubble,
  block handle, find bar and page menu; typing, saving and reopening a page.
- **Spec review: FAIL, then fixed.** Seven blockers, each now covered by a
  test that failed first:
  - entities and escaped HTML turned into formatting, and typed `<u>`, `&amp;`
    and `$x$` read back as HTML or maths (text is now escaped);
  - link reference definitions deleted (now kept blocks; references are
    written inline);
  - images rebuilt and corrupted (now sliced from the source);
  - invisible marks moved or dropped before a divider, a kept block or the
    end (now kept where they were);
  - front matter closed at a `---` mid-line, and a page opening with a
    divider read as front matter;
  - an unclosed `<u>` gained a close, and an unknown span closed a colour
    early (tags are now paired first);
  - a Document pane mounted again after a failure saved an empty page
    (`markdown()` is `null` before a page; the page is handed to a new pane).
- **Also from the review:**
  - An untouched page saves exactly as it was read; tidying happens only
    when its prose or settings change.
  - Every real Markdown file in the repo must show the same in a viewer
    after one save.
  - Front matter keeps its `bava:` lines in order, `locked: false`
    included, and a header written empty stays.
  - Cut copies kept blocks, and paste never reads front matter.
  - ⌥⌘F puts the caret in the replace field, and the find bar takes focus.
  - Find, the drop cursor and the pressed state now use tokens.
  - `LinkField` became a component, sharing `.bava-field` with FindBar.
  - The handle hides while you type.
  - The handle's + opens the `/` menu on a new line, or on the empty line
    itself.
  - ⌘E is reserved from the menu; dead code and process references removed.
  - By the user's choice, ⌘/ opens the block menu for the caret's block and
    Alt+F10 moves into the bubble (arrows along it, Escape back).
- **Deviations kept:**
  - Headings 4 to 6 are listed flat in the `/` menu, not under "More
    headings".
  - Dragging moves one block, not a selection of blocks.
  - Test pages are written inline in the tests; there is no `docs/fixtures/`.
  - A tab inside a kept block within a list item is written as spaces.
