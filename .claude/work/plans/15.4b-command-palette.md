# 15.4b: The command palette

**Goal:** run any menu command by name from a palette over the window.
**Specs:** `.claude/work/specs/canvas-work.md` decisions 5 to 7;
`.claude/work/specs/search.md` (the palette it is modelled on).
**File format impact:** none. **UI impact:** a new palette (drawn as the
mockup's "8.2 The command palette"), a View menu item.

## Constraints

- "Every menu command by name, with its menu path and its keys; Enter runs
  it; commands that cannot run now are left out. Pages stay with Search."
- "⇧⌘P opens the palette (Ctrl+Shift+P on Windows and Linux)."
- "Opened, the palette lists recent commands, then all by menu ... kept in
  memory for the session, never saved."
- No document state in browser storage; `components/` are presentational.
- Undo is per editor and Edit commands go where focus is: a command run from
  the palette acts where focus was before it opened.

## How it works

- **When an item can run is written once, in `spec.json`**: an item may
  carry `when`, the menu states it needs, all of them (`hasSelection`,
  `hasSpace`, `hasDocument`, `showsCanvas`, `canPasteStyles`, `hasLocked`).
  Go's `Built.Apply` enables items from it instead of its lists, and the
  palette leaves out what it says cannot run, from the same state App
  already sends Go.
- **The commands** (`shell/palette.ts`): from the spec for this platform,
  every `command`, `checkbox` and `radio` item with an id, its label, its
  menu path ("File ▸ Export") and its keys; never a role, a submenu or the
  recent files. Matching: every typed word, in any order, appears in the
  label or the path, ignoring case; label matches first, then menu order.
  Recent: the last five run from the palette, newest first, in memory.
- **The palette** (`components/CommandPalette.svelte`): presentational, the
  search palette's frame and keys: a field, rows grouped (Recent, then each
  menu) with the path muted and the keys as keycaps, the typed words
  marked; ↑ ↓ move, Enter runs, Escape or a press outside closes.
- **Running:** the palette closes and focus goes back to where it was, then
  the command goes through the same dispatcher a menu click does.
- **Opening:** View ▸ Command Palette, `Shift+CmdOrCtrl+P`, native.

## As built (2026-10-12)

View ▸ Command Palette (⇧⌘P, native) opens `CommandPalette` over the window:
every menu command for this platform by name (`shell/palette.ts`:
`paletteCommands`), its menu path where the group does not say it, its keys
as keycaps. Opened, it lists the recent commands (five, newest first, the
session only) and then every command under its menu; typed, the commands
holding every word, label matches first, the words marked. Enter runs the
command after the palette has closed and given focus back, through the
menu's dispatcher. What an item needs to run is written once, as `when` in
`spec.json`; Go's menu enables from it (the lists in `build.go` are gone)
and the palette leaves out what cannot run, from the state App sends Go.

**Deviations**
- The menu state App sends Go is now a `$derived` shared with the palette.
- A new token, `--size-command-palette`, narrower than Search's; and a
  `command` icon.
- A `State.Set` helper exists for the menu tests only (`export_test.go`).

**Red first:** the spec and build tests for `when`, the command list, the
grouping, the component and the five browser tests were each seen failing
first. The two focus tests were checked by switching the focus restore off
(both failed).

**Pictures:** new `dialogs/palette--opened` and `palette--typed`; changed
`dialogs/shortcuts--default` (the Command Palette row) and
`components/sheet--controls` (the command icon); both themes, each read.

**Owed at a running window:** `docs/release-checklist.md` (⇧⌘P on each
system, in the page, the canvas and the code editor; Undo from it).

**Review** (spec-reviewer: PASS, eight warnings, seven acted on):
- The palette waits while Search or a dialog is open, and Search takes over
  from it, the keys given back first.
- The palette never offers itself.
- The highlighted row stays within the list however it changes while open.
- A command runs after `tick()`, the palette gone and focus back, so an Edit
  command can never act on the palette's own field; Select All on the
  canvas is tested.
- `docs/ipc.md`'s state table follows `when` (Zoom to Selection, Import).
- Tests for a press outside, and a recent command that can no longer run.
- The palette's words have their own comment; no `aria-label` on a plain
  span inside an option.
