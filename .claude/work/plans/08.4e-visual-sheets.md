# 08.4e: Visual sheets

> Historical: built and committed; see the roadmap for what followed.

**Goal:** the visual regression layer pictures each family of things once per
theme on a sheet, states are checked as data, behaviour leaves the visual
walks, the known flakes are gone, and every CI build can be downloaded.
**Specs:** `docs/testing.md`, `.ai/rules/testing.md`, `.ai/rules/design-system.md`,
plan `08.4d-test-layout.md` (layout and layer names), the testing comparison
of 2026-10-04 (Excalidraw, tldraw, Penpot, BlockSuite, Konva: tens of
pictures, rendering output over UI states, state checked as data).
**File format impact:** none.
**UI impact:** selected text gets Bava's own colour (`--color-selection`),
the same in an active and an inactive window, on every platform. No
component added.

## Decisions (2026-10-04, with the user)

1. Every picture in both themes, screens included.
2. Selected text uses a Bava colour, not the system highlight.
3. Each CI build is kept as a download for all three systems, 14 days.
4. A picture shows a finished state. How it got there (pressing, dragging,
   typing) is proven by unit or integration tests, not by a walk of pictures.

## The rule for a picture

A picture exists only when it shows something no other picture or test
shows. A family of things sits on one sheet, its states side by side. A
state that a test can read from the page (pressed, disabled, checked, open,
chosen, the count of rows) is asserted as data; the sheet still shows it,
once, so its look is guarded.

## Constraints

- Comparison stays `maxDiffPixels: 0`, `threshold: 0.02`.
- Visual tests set their state through fixtures (`seedScene`, the sample
  Space's pages) or one direct action; no walk of several steps.
- Forced states exist only in the browser-test build (`vite.visual.config.ts`);
  the app's build never contains them (checked by a test).
- Every behaviour a removed walk asserted is still asserted somewhere,
  listed in the As built with where it went.
- No git write operations.

## As built

The boxes above were left unticked; this section is the record of what
was done.

**Pictures: 1,157 to 248** (124 per theme): components 38, canvas 76,
document 48, dialogs 44, settings 8, shell 18, space 12, start 4. More than
the plan's estimate of about 136: dialogs kept the variants with a layout of

**Deviations**

- **Task 1.** The `::selection` rule is in (`styles/base.scss`, tested).
  Pinning the colour did not stop the callout flake: headless WebKit dims
  any selection colour by a window state that is neither the page's focus
  (probed 60 times) nor `bringToFront`, and a rule for an inactive window
  made no difference (tried, removed). Three attempts, then a different
  approach: pictures leave the text selection out
  (`harness/screenshot.css`, Playwright's `stylePath`). 80 of 80 after.
- **Task 2.** The export flake did not reproduce (40 alone, 417 integration
  runs). The test now asserts the two things its result depends on: the
  dialog closed and a shape is selected.
- **`placed()`** also requires a floating piece inside the window: the
  opacity popover could hold still at the window's bottom edge before Ark
  placed it (2 in 30).
- **Forced states** leave a state inside `:not()` alone: `:not(:hover)`
  rewritten matched every element and hid the code block's Copy button
  under a real pointer (caught by an integration test).
- **Dropped as showing nothing new:** the right-click submenu picture (same
  menu styles; keyboard opening is unit- and integration-tested), splitter
  dragged (no look of its own), Files tree renaming (same field as naming).
- **Settings:** four tabs, not five (Appearance, Files, Canvas, Advanced).
- **IN_SCREENS:** MediaViewer is pictured in the document (full screen),
  Splash in the shell.
- **The stand-in's `SetVerbose`** now saves the setting first, as Go does.
- **Unused gallery demos removed** (About, Diagram, Dialog, Error, Export,
  MediaViewer, NewSpace, Shortcuts, SpaceSettings, Splash); the gallery
  guard keeps a demo only for a sheet component or one a spec opens.
