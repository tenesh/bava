# 08.3d: A block before or after any block; no toggle headings

**Goal:** from anywhere in the Document, one way adds an empty block before
or after the block you are in, the page always ends with an empty line, and
toggle headings go (the toggle list is the one fold).

**Specs:** `.claude/work/specs/08-documents.md` decisions 17 (empty lines are
not saved), 43, 79 (reversed), 84, 90 and 91; `docs/shortcuts.md`; `.ai/rules/editors.md`,
`.ai/rules/design-system.md`.

**File format impact:** none written differently. Empty lines are not
written, so a page reads and saves as before; an untouched page still saves
byte for byte. `docs/file-format.md` loses the toggle heading: an old
`<!-- bava: toggle -->` mark is an unknown key, kept as written.

**UI impact:**
- **Keys:** ⌘Enter and ⇧⌘Enter (Ctrl on Windows and Linux).
- **Block menu:** Add a block before, Add a block after.
- **The handle's `+`:** ⌥-click adds above.
- **No new component or token.**

## Constraints

- **Nearest block** (decision 90): the innermost block that can have a line
  beside it. A cell cannot hold a second block, so in a table it is the
  table.
- **Leaving a container takes a second press.** ⌘Enter on an empty last line
  of a quote, callout or toggle moves that line out, after the container, as
  Enter on an empty list item leaves a list; ⇧⌘Enter on an empty first line
  moves it out before.
- **The caret goes to the new line.** The handle's `+` also opens the `/`
  menu there, as it does today; the keys and the block menu do not.
- **The page always ends with an empty line**, before the notes when there
  are footnotes. It is never saved, and it is not an undo step of its own.
- **A locked page:** nothing is added.
- **Footnotes stay at the foot:** a line is never moved out of a note.

## What each block does

"After" is ⌘Enter; "before" is ⇧⌘Enter, the same with the new line on the
other side. A block that holds no caret (divider, equation, contents, kept
block, a selected table) is reached selected: click it, or select it from
the handle.

| Where the caret is | ⌘Enter | ⇧⌘Enter |
|---|---|---|
| Text or a heading, on the page | A line after it | A line before it |
| A list item's text (bulleted, numbered, to-do) | A new empty item after it, same kind (a to-do unticked) | A new empty item before it |
| A line after a list item's text (more lines in the item) | A line after it, in the item; empty and the item's last: a new item after | A line before it, in the item; empty and right after the item's text: a new item before |
| An empty last item of a list | Out of the list: a line after it (as Enter does); in a nested list, a new item of the list around it, or a line in its item when more of the item follows | A new empty item before it |
| An empty item in the middle of a list | Leaves one level, as Enter does: an item of the list around it, or a line between the list's two halves (one holding a nested list gets a new item instead, as Enter does) | The same |
| An empty first item of a list | A new empty item after it | Out of the list: a line before it; in a nested list, a line in its item before the nested list |
| A line in a quote, a callout or a toggle's body | A line after it, inside | A line before it, inside |
| An empty last line of a quote, callout or toggle | Moved out: a line after the container | A line before it, inside |
| An empty first line of a quote, callout or toggle | A line after it, inside | Moved out: a line before the container |
| A toggle's title | A line after the whole toggle, open or folded (Enter goes into its body, opening it) | A line before the toggle |
| A code block | A line after it (as today) | A line before it |
| A table cell, or cells selected | A line after the table | A line before the table |
| A line in a footnote's note | A line after it, in the note | A line before it, in the note |
| A selected divider, equation, contents block, kept block or table | A line after it | A line before it |
| Nested: a list in a callout, a quote in a list item, a callout in a toggle, a table in a quote | The innermost of the above; each further press on the empty line moves out one level, from an edge line or any empty list item (an empty line in the middle of a quote, callout or toggle stays inside) | The same, before |
| The page's last line (empty) | A line after it (a second empty line) | A line before it |

The handle's `+` and the block menu act on the block the handle is beside:
a whole list, quote, callout, toggle or table.
